## LED 显示功能

系统配备两颗 WS2812 RGB LED：  
- **sysRGB**（系统灯，引脚 15）—— 指示系统和连接状态。  
- **modeRGB**（模式灯，引脚 7）—— 及电机运行方向及是否过载斩波。

    指示灯	                   场景	                            显示效果

系统灯 (sysRGB)	        启动中 / 脚控掉线	                黄色慢闪（亮 1s 灭 1s）
                        脚控在线，一切正常	                绿色常亮
                        任何故障（H桥/步进/INA/过热）	    红色快闪（亮 200ms 灭 200ms）——最高优先级

动力灯 (modeRGB)	    正转（轻载）	                    蓝色常亮
                        反转（轻载）	                    绿色常亮
                        正转 + 斩波限流（重载）	            蓝色快闪（200ms 间隔）
                        反转 + 斩波限流（重载）	            绿色快闪（200ms 间隔

> **亮度**：默认为 20（0~255），可通过 Web 面板调整，并持久生效。

## 按钮功能

系统提供两个物理按键：**加速按钮（ACCEL，引脚 40）** 和 **减速按钮（DECEL，引脚 41）**，均采用下拉输入，高电平触发。  
使用 `OneButton` 库识别短按（< 800ms）和长按（≥ 800ms）。

### 加速按钮（ACCEL）

| 操作 | 当前模式 | 功能 |
|------|----------|------|
| **短按** | 手动模式 | 电机档位 **+1**（正转方向，范围 1~5） |
| **短按** | 脚控模式 / 巡航模式 | 步进电机速度档位 **+1**（范围 1~5） |
| **长按** | 任意模式 | **切换 Web 服务器**（启动/停止），同时蜂鸣器长鸣 1 秒表示切换 |

> 短按时蜂鸣器短鸣 200ms，长按时蜂鸣器长鸣 1000ms。

### 减速按钮（DECEL）

| 操作 | 当前模式 | 功能 |
|------|----------|------|
| **短按** | 手动模式 | 电机档位 **-1**（反转方向，范围 -1~-5，0 为停止） |
| **短按** | 脚控模式 / 巡航模式 | 步进电机速度档位 **-1**（范围 1~5） |
| **长按** | 任意模式 | **切换电机旋转方向反转标志**（`isDecelButtonLongPressed`），同时蜂鸣器长鸣 1 秒 |

> 方向反转标志会影响步进电机的运动方向（在脚控/巡航模式下，结合左右转向指令）。

### 按键消抖与互斥

- 短按与长按采用 **800ms** 去抖阈值，互不干扰。
- 长按状态为 **电平切换**（toggle），每次长按取反标志位。
- 所有按键操作均在 `buttonTask` 中轮询处理（50ms 周期），不影响实时控制任务。
